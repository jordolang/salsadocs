# Owner Runbook

These pages cover the jobs that need **you**: someone signed in to Google, Vercel and
BigCommerce as the owner. No developer or AI agent has those logins, so these steps can't be
done in code. Each page says what the job is for, what you need before you start, the exact
clicks, and how to tell it worked.

<Callout type="warn" title="Never paste a secret anywhere but the place the step names">
Several steps hand you a password-like value (a JSON key file, an API token). Paste it only
into the screen the step tells you to. Don't email it, put it in a chat, or commit it to
GitHub. If one leaks, delete it where it was created and make a new one.
</Callout>

## Suggested order

<Steps>
<Step>
**Replace the Google Analytics key.** It's independent of everything else and takes about
15 minutes.
</Step>
<Step>
**Place the BigCommerce test order and refund it.** It proves checkout works before you put
the new domain in front of more shoppers.
</Step>
<Step>
**Connect the trackers in BigCommerce**, so purchases count from launch day.
</Step>
<Step>
**Finish the josemadridsalsa.com launch.**
</Step>
<Step>
**Search Console for the fundraising site.** Any time.
</Step>
</Steps>

## Accounts you'll need

- **Vercel**, on the team that owns the `josemadridsalsa` project.
- **Google**, the account that owns the Google Analytics property and the Search Console
  properties. Use the same one throughout; Search Console verification is tied to it.
- **Google Cloud console** (console.cloud.google.com), same Google account.
- **BigCommerce**, store owner login for the main store (josemadridsalsa.com).
- **Website admin** (`/admin`) with an Admin role.
