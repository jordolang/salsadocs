# Verify fundraising.josemadridsalsa.com in Search Console

**Why:** Search Console is where Google tells you whether it can find and index a site's
pages. The fundraising site has its own address and its own sitemap, so it needs its own
entry ("property") to submit that sitemap and see its search results.

**Time:** 10 minutes, then a check-back in a few weeks.

**You need:** the Google account that manages the website's Search Console properties
(`josemadrid.net`, and `josemadridsalsa.com` once the [launch](/docs/owner-runbook/launch-josemadridsalsa-com)
step adds it).

<Callout type="info" title="Ready to do">
The fundraising site has its own Vercel project and has served the fundraising pages at
`fundraising.josemadridsalsa.com` since 7 October 2026 (josemadridsalsa #577). The old
`fundraising.josemadrid.net` address redirects there, so set up the new address only.
</Callout>

<Steps>
<Step>
### See whether it's already covered

Go to **search.google.com/search-console** and open the property list (top left).

- If there's a property called just **josemadridsalsa.com** (no `https://`), that's a *Domain
  property*. It already covers every subdomain, so `fundraising.josemadridsalsa.com` is verified.
  You can still add the separate property below to get the fundraising site's own reports and
  submit its sitemap; it will usually verify instantly.
- If you only see URL-prefix properties (ones starting with `https://`), continue with step 2.
</Step>

<Step>
### Add the property

1. **Add property**.
2. Choose the right-hand box, **URL prefix**, and enter `https://fundraising.josemadridsalsa.com/`.
3. Click **Continue**.
</Step>

<Step>
### Verify ownership

Pick **HTML tag** from the list of methods and click **Verify**. The fundraising site already
carries the same verification tag as the main site, so this passes when you're signed in as
the Google account that verified the main site.

If it fails ("couldn't find your meta tag" or a different code), use a DNS record instead:

1. In Search Console, choose **Domain name provider** and copy the `google-site-verification=...`
   text it shows.
2. Add a DNS record where josemadridsalsa.com's DNS is managed (Vercel → **Domains** at team
   level → **josemadridsalsa.com** → **DNS Records** → **Add**, if Vercel manages it):
   - Name: leave empty (or `@`)
   - Type: `TXT`
   - Value: the text you copied
3. Wait a few minutes, then click **Verify** in Search Console.
</Step>

<Step>
### Submit the sitemap

In the new property: **Sitemaps** (left menu) → enter `sitemap.xml` → **Submit**. The full
address is `https://fundraising.josemadridsalsa.com/sitemap.xml`. Status should read **Success**
within a day. It lists the home page, the shop and its products, and every group page.
</Step>

<Step>
### Ask Google to crawl the key pages

In the top search bar of the property, run **URL Inspection** on each of these and click
**Request indexing**:

- `https://fundraising.josemadridsalsa.com/`
- `https://fundraising.josemadridsalsa.com/shop`
- `https://fundraising.josemadridsalsa.com/groups`
- `https://fundraising.josemadridsalsa.com/start`
</Step>
</Steps>

## Check it

- [ ] The property shows as verified (Settings → Ownership verification).
- [ ] Sitemaps shows `sitemap.xml` with status **Success** and a discovered-page count above zero.
- [ ] **In a few weeks:** Pages (Indexing) shows the indexed count rising. If it stays at zero,
      check the **Why pages aren't indexed** table there.

## If an old fundraising.josemadrid.net property exists

If someone already added `https://fundraising.josemadrid.net/` as a property, open it and try
**Settings → Change of address** to point Google at `fundraising.josemadridsalsa.com`. If Search
Console doesn't offer it for that property, the redirect plus the new sitemap are enough; Google
follows them on its own.
