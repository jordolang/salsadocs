## Buying a gift certificate

Go to [Buy a gift certificate](https://www.josemadridsalsa.com/gift-certificates/purchase), choose an amount from $1 to $500, add a message, and pay. As soon as the payment goes through, the recipient gets an email with a code that looks like `JMS-GC-XXXX-XXXX`.

## Checking your balance

Enter your code on the [balance page](https://www.josemadridsalsa.com/gift-certificates/balance), or use the link in your gift certificate email. Whatever you don't spend stays on the certificate for your next order.

## Using a gift certificate

1. Add salsa to your cart and go to checkout.
2. Enter your code in the discount / gift certificate field.
3. If the certificate covers the full total, you're done. Otherwise, pay the rest with a **card or Link**.

<Callout type="warn">
While a gift certificate is applied, **PayPal, Venmo, and Cash App Pay aren't available** for that order.
</Callout>

## Common questions

<Accordions>
  <Accordion title="My code says it's invalid">
    Double-check the code for typos. Codes that start with `JMS-GC-` never use the letters **O** or **I** or the numbers **0** or **1**, so if you see one, it's the other. Copy and paste it from the email if you can. Still stuck? [Contact us](https://www.josemadridsalsa.com/contact) with the code and we'll check it.
  </Accordion>
  <Accordion title="Can I use a gift certificate on a fundraiser order?">
    No. Fundraiser orders support a group's campaign, so use your gift certificate on a regular salsa order instead.
  </Accordion>
  <Accordion title="Can I return a gift certificate?">
    No, gift certificates are non-returnable.
  </Accordion>
</Accordions>
